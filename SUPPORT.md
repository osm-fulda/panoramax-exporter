# Support

- **Bug or missing metric** → open a [GitHub issue](https://github.com/osm-fulda/panoramax-exporter/issues).
- **Question about usage** → also an issue; there is no separate forum.
- **Security problem** → see [SECURITY.md](SECURITY.md), not a public issue.

Questions about Panoramax itself (the API, the instance, uploads) belong with the
upstream project at [panoramax.fr](https://panoramax.fr/), not here.
